# 常见问题

**ZIP 显示不可读取或没有封面？** 检查压缩包是否损坏、加密，或书库目录是否移动。加密 ZIP、RAR、7z 暂不支持；不要修改原压缩包。若旧书库需要原生授权，请选择原主目录。

**「显示位置」要求重新选文件夹？** 这是 Windows 原生文件访问授权确认，不是重新导入。选择与当前书库对应的原主目录；取消不会删除书库记录。

**缩略图栏不出现？** 将鼠标移到阅读器底边，或按 `T` / `B`，也可点左下按钮。触控或键盘用户可用备用操作。

**鼠标侧键不能翻页？** 浏览器运行环境或设备驱动可能先处理侧键。改用方向键或画面两侧按钮，并在 Issue 中注明设备型号，不要附个人图库。

**升级后找不到书库？** 先确认选择的是原目录、磁盘仍连接、权限有效。不要卸载重装或删除 UserData。关闭应用并保存原图与应用数据备份后，再通过 [Issue](https://github.com/k-kaiko/KaikoLibrary/issues) 说明现象。

**安装器提示缺少 WebView2？** 检查网络，或从[微软官方页面](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)安装 Runtime。首次 Beta 安装包尚无可信发布者数字签名。
