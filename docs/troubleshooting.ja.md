# よくある問題

**ZIP が読めない・表紙がない：** 破損、暗号化、主フォルダーの移動を確認してください。暗号化 ZIP、RAR、7z は非対応です。元 ZIP を変更しないでください。旧ライブラリの権限確認には元の主フォルダーを選びます。

**［場所を表示］でフォルダーを再選択する：** Windows のネイティブなファイルアクセス権限の確認で、再登録ではありません。対応する元の主フォルダーを選んでください。キャンセルしても登録は削除されません。

**サムネイル欄が出ない：** 画面下端へポインターを移動するか、`T` / `B` または左下ボタンを使用してください。タッチ・キーボードでも代替操作ができます。

**マウスのサイドボタンが効かない：** ブラウザー実行環境やドライバーが先に処理する場合があります。矢印キーや画面端のボタンを使い、Issue には機器の型番を記載してください。コレクションは添付しないでください。

**更新後にライブラリが見つからない：** 元フォルダー、ドライブ接続、権限を確認してください。アンインストールや UserData の削除はしないでください。アプリを閉じ、元画像とアプリデータのバックアップを保管してから [Issue](https://github.com/k-kaiko/KaikoLibrary/issues) に状況を記載してください。

**セットアップで WebView2 が必要：** ネット接続を確認するか、[Microsoft の公式ページ](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)から Runtime をインストールしてください。最初の Beta インストーラーには信頼された発行者の署名がありません。
