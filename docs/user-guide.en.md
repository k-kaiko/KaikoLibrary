# User guide

## Create a bookshelf

Select **Add library** and choose a root folder containing your works. Add photo roots through **Photo libraries** in the sidebar. Works can be image folders or ordinary ZIP files; nested folders remain navigable. Browsing does not move or copy originals. The optional first-use guide can be reopened from **Settings & help**.

For an older library, ZIP reading or **Show location** may ask you to select the **same original root** for native Windows file authorization. This is not a reimport. If access fails, first check that the original folder still exists.

## Organize and find

Select a cover to read or enter a subfolder. Use the heart for favorites, plus tags and groups for organization. Confirm a search after typing, then combine it with sorting, filtering, and pagination. Drag root libraries to reorder them. A card's `+N` shows all tags read-only; the tag icon edits them. Possible duplicates are shown with reasons; moving a work to the Recycle Bin requires confirmation.

## Read

**Fit Page** is the default, with **Comfortable width** available. The wheel zooms around the pointer; hold the left button and drag to pan. Arrow keys, edge buttons, and mouse side buttons on some systems turn pages. Press `0` to fit the page again.

Approaching the reader's bottom edge opens thumbnails; they close after a delay when you leave. `T`, `B`, or the lower-left button also toggles them. Select a thumbnail to jump. Esc exits fullscreen; from windowed reading it returns to the source shelf; on the shelf it ascends folders. Dialogs and temporary suggestions close first.

## Language, themes, and data

Use **Settings & help** for 简体中文, English, 日本語, and four themes. Work titles, file names, and user tags are not translated. Progress and other associations are stored locally. Close the app before backing up both originals and `%LOCALAPPDATA%\KaikoLibrary\UserData`. Encrypted ZIP, RAR, and 7z are not supported. See [troubleshooting](troubleshooting.en.md).
