# User guide

KaikoLibrary v1.4.0
Public attribution: Kaiko

Selection: Select this page, then click covers to exclude works. Paging keeps the task. Leaving selection mode or changing library, search or tag filters clears it. Success keeps both the selection and selection mode; cancelling preserves it. Filename suggestions are editable and require preview and confirmation; no network or image analysis is used. The add button beside the library heading uses the existing binding flow.

Libraries: Select Add library for a comics root, or add a photo root in Photo library. Image folders and ordinary ZIP files can appear as works; originals stay where they are. Native ZIP access or Show location may ask you to confirm the original library root again; this is not a reimport.

Organize: Select a cover to read or enter a folder; in selection mode it selects the work instead. Cover actions at the top-right offer favorites, groups, tags and location, also available by right-click or keyboard. Settings can keep these actions visible. Batch tags: select works, choose or enter one tag, add or remove, preview, acknowledge, then apply. Session undo remains available. +N only shows all tags. Confirm searches; combine them with sort and filters.

Read: Fit Page is the default. Reading settings offer single, double and vertical layouts. The bottom edge reveals a compact strip; expand larger thumbnails when needed and use the wheel to browse them horizontally. T/B or the lower-left fallback button toggles the controls; a setting keeps them visible. Select the page count to jump. The default wheel zooms around the pointer; Ctrl+wheel always zooms. Left-drag pans. Arrow keys, PageUp/PageDown and Space turn pages or scroll; 0 restores fit.

Back: Esc closes dialogs and temporary suggestions first, exits fullscreen from fullscreen reading, leaves a windowed work for its source shelf, then ascends shelf folders. Drawer visibility does not add an Esc step. Esc at a library root does not quit the app.

The optional first-use guide opens automatically only for a new profile and is available again under Settings & help. That menu also offers three languages, four themes and grouped help.

Data: Library links, favorites, tags and progress stay in local WebView2 UserData; originals stay in their folders. Close the app before backing up originals and %LOCALAPPDATA%\KaikoLibrary\UserData. Do not delete UserData or reinstall to fix a folder permission issue. Encrypted ZIP, RAR and 7z are unsupported. A browser or driver may intercept mouse side buttons.

Upgrade: Close the app, then run KaikoLibrary.v1.4.0.Setup.exe yourself. It replaces earlier versions without uninstalling. Keep your earlier installer if you may need to restore program files.

Shelf paging: nearby page numbers adapt to the window. Select current/total to jump or reach the first/last page. Clearing the final tag filter returns to the valid source folder, with a safe library-root fallback if unavailable. Select Finish organizing to leave selection mode and clear the selection.
