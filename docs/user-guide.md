# 基础使用指南

KaikoLibrary v1.4.0 正式版
对外署名：Kaiko

多选整理：可全选当前页并点封面排除；同一任务翻页保留。退出多选、更换书库或搜索／标签筛选会清空；成功应用后保留选择和多选模式，取消保留。可展开文件名候选词并编辑，仍需预览确认，不使用网络或图像识别。普通书库标题旁的添加按钮复用既有绑定流程。

书库：点击“添加书库”，选择漫画主目录；照片主目录可从侧栏“照片图库”添加。文件夹和普通 ZIP 可作为作品，原图留在原目录。旧书库使用 ZIP 或“显示位置”时，如需原生授权，请再次选择原主目录，这不是重新导入。

整理：点击封面阅读或进入下级目录；多选模式下改为选择作品。封面右上操作区提供收藏、分组、标签和显示位置，右键或键盘也可访问；可在设置中保持操作区显示。批量标签：选择作品 → 选择或输入一个标签 → 添加或移除 → 预览并勾选确认 → 执行；本次会话可撤销。+N 仅查看全标签。搜索需确认后执行，可结合排序与筛选。

阅读：默认整页适屏；阅读设置中可切换单页、双页和连续纵向。鼠标靠近底边先显示简洁控制条，再按需展开大缩略图；滚轮可横向浏览缩略图。T/B 或左下备用按钮手动开关控制层，可在阅读设置中保持显示。点当前页码跳页。默认滚轮以光标缩放，Ctrl＋滚轮始终缩放，左键拖动平移；方向键、PageUp/PageDown、空格翻页或滚动，0 恢复适屏。

返回：Esc 先关闭弹窗或搜索候选；全屏时退出全屏，窗口阅读时返回来源书架，书架中逐级返回主目录。缩略图栏的展开状态不改变这套顺序，Esc 不会在书库主目录退出程序。

首次引导只自动显示给真正的新用户，可跳过，并可从“设置与帮助”重新打开。该菜单还提供三语言、四主题与分组帮助。

数据：个人关联、标签、收藏和进度保存在本机 WebView2 UserData；原图在原位置。备份前关闭应用，再备份原图及 %LOCALAPPDATA%\KaikoLibrary\UserData。不要通过删除数据或重装解决授权问题。加密 ZIP、RAR、7z 不受支持；鼠标侧键可能被浏览器或驱动优先处理。

升级：关闭应用后自行运行 KaikoLibrary.v1.4.0.Setup.exe。可覆盖旧版，不需卸载；保留旧安装包以便恢复程序文件。许可详见随包文件。

书架分页：顶部按窗口宽度显示邻近页码，点当前页／总页数可直接跳页或到首页、末页。取消最后一个标签筛选会返回有效的来源目录；来源失效时安全回到可用的书库根目录。再次点击“完成整理”退出多选并清空选择。
