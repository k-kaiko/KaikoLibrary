# 基础使用指南

## 建立书架

点击「添加书库」，选择存放作品的主文件夹；照片目录可从侧边栏「照片图库」添加。作品可为包含图片的文件夹或普通 ZIP。下级文件夹可继续进入。原始文件不会因为浏览而被移动或复制。初次引导可跳过，也可在「设置与帮助」重新打开。

旧书库在使用 ZIP 阅读或「显示位置」时，可能需要再次选择**原主目录**以完成 Windows 原生授权；这不是重新导入。授权失效时先检查原文件夹是否仍存在。

## 整理和查找

点击封面阅读或进入下级目录；用心形收藏，用标签和分组整理。搜索词输入完成后确认搜索，再配合排序、筛选及分页浏览。常用书库和照片图库中的主目录可拖动调整顺序。卡片的 `+N` 只读展示全部标签；标签图标负责编辑。重复作品入口展示候选与依据，删除动作需再次确认。

## 阅读

默认「整页适屏」，另有「舒适宽度」。鼠标滚轮以光标为中心缩放，按住左键拖动图片平移；方向键、两侧按钮和部分设备的鼠标侧键可翻页。按 `0` 恢复适屏。

鼠标靠近阅读器底边会呼出缩略图栏，离开后延迟收起；按 `T`、`B` 或左下按钮也能切换。点击缩略图跳页。全屏时 Esc 退出全屏；窗口阅读时 Esc 返回来源书架；书架内 Esc 逐级返回主目录。弹窗和临时候选优先关闭。

## 语言、主题和数据

在「设置与帮助」切换简体中文、English、日本語及四套主题。作品名、文件名和用户标签不会被翻译。阅读进度、标签等关联数据保存在本机；备份时关闭应用并分别保存原图与 `%LOCALAPPDATA%\KaikoLibrary\UserData`。加密 ZIP、RAR、7z 暂不支持。详见[常见问题](troubleshooting.md)。
