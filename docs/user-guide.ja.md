# 基本ガイド

KaikoLibrary v1.4.0
対外的な制作者表記：Kaiko

複数選択：現在ページを全選択し、表紙で一部を解除できます。同じ作業のページ移動では保持し、選択モード終了やライブラリ・検索・タグ絞り込みの変更で解除します。適用成功後も選択と選択モードを保持し、キャンセル時も保持します。ファイル名候補は編集可能ですがプレビューと確認が必要で、ネットワークや画像解析は利用しません。通常ライブラリ見出しの追加ボタンも既存の登録手順を使います。

ライブラリ：［ライブラリを追加］で漫画の親フォルダーを、サイドバーの［写真ライブラリ］で写真の親フォルダーを選びます。画像フォルダーと通常の ZIP を作品として表示でき、元画像は元の場所に残ります。ZIP や［場所を表示］で元の親フォルダーの確認を求める場合がありますが、再登録ではありません。

整理：表紙を押すと閲覧または下位フォルダーへ移動し、複数選択中は作品の選択に変わります。表紙右上の操作部からお気に入り、グループ、タグ、場所を利用でき、右クリックやキーボードでも操作できます。設定で常時表示も可能です。一括タグは作品を選び、タグを一つ選択または入力し、追加・解除を選び、プレビューと確認後に適用します。同じセッション内で取り消せます。+N は全タグの閲覧専用です。検索は確定後に実行し、並べ替えや絞り込みと併用できます。

閲覧：初期表示はページ全体表示です。閲覧設定で単ページ、見開き、縦スクロールを選べます。下端で簡潔な操作バーを表示し、必要に応じて大きなサムネイルを展開します。ホイールでサムネイルを横移動できます。T/B または左下の補助ボタンで操作部を切り替え、設定で常時表示もできます。ページ数を押すと指定ページへ移動します。初期設定のホイールと Ctrl＋ホイールは拡大縮小、左ドラッグは移動です。矢印、PageUp/PageDown、スペースでページ送りまたはスクロール、0 で全体表示に戻します。

戻る：Esc は先にダイアログや一時候補を閉じ、全画面閲覧では全画面を解除し、ウィンドウ閲覧では元の本棚へ戻り、さらに上位フォルダーへ戻ります。サムネイルの表示状態は Esc の段階を増やしません。主フォルダーでアプリは終了しません。

任意の初回ガイドは新しい設定にだけ自動表示され、［設定とヘルプ］から再表示できます。同じメニューで三言語、四テーマ、項目別ヘルプを利用できます。

データ：関連付け、タグ、お気に入り、進捗はローカル WebView2 UserData に保存され、元画像は元のフォルダーに残ります。バックアップ前にアプリを終了し、元画像と %LOCALAPPDATA%\KaikoLibrary\UserData を保存してください。権限問題のためにデータを削除したり再インストールしたりしないでください。暗号化 ZIP、RAR、7z は非対応です。サイドボタンはブラウザーやドライバーが先に処理する場合があります。

更新：アプリを閉じてから KaikoLibrary.v1.4.0.Setup.exe をご自身で実行してください。アンインストールせずに旧版を上書きできます。旧インストーラーはプログラムを戻す場合に備えて保管してください。

本棚のページ番号は幅に応じて表示します。現在／総ページ数から指定ページ・最初・最後へ移動できます。最後のタグ絞り込みを解除すると有効な元フォルダーへ戻り、無効なら利用可能な主フォルダーへ安全に戻ります。［整理を終了］で複数選択を終了し、選択を解除します。
