# 基本ガイド

## 本棚を作る

［ライブラリを追加］から作品の主フォルダーを選びます。写真の主フォルダーはサイドバーの［写真ライブラリ］から追加します。画像フォルダーと通常の ZIP を作品として扱い、下位フォルダーも開けます。閲覧によって元ファイルは移動・複製されません。初回ガイドは［設定とヘルプ］から再表示できます。

旧ライブラリの ZIP 閲覧や［場所を表示］で、Windows のネイティブなファイル権限のために**元の主フォルダー**の選択を求める場合があります。再登録ではありません。アクセスできない場合は、元フォルダーの存在を先に確認してください。

## 整理と検索

表紙から閲覧または下位フォルダーへ移動します。ハートでお気に入り、タグとグループで整理します。検索語は入力後に確定し、並べ替え・絞り込み・ページ切り替えと併用できます。主フォルダーはドラッグで表示順を変更できます。カードの `+N` は全タグの読み取り専用表示、タグアイコンは編集用です。重複候補には判断理由を示し、ごみ箱へ移す前に確認します。

## 閲覧

初期表示は［ページ全体表示］で、［快適な幅］にも切り替えられます。ホイールでポインターを中心に拡大縮小し、左ドラッグで画像を移動します。矢印キー、画面端のボタン、一部環境のマウスサイドボタンでページを送ります。`0` で全体表示に戻ります。

画面下端へ近づくとサムネイルが開き、離れると遅れて閉じます。`T`、`B`、左下のボタンでも切り替えられます。サムネイルを選ぶとそのページへ移動します。Esc は全画面を解除し、ウィンドウ閲覧では元の本棚に戻り、本棚では上位フォルダーへ戻ります。ダイアログや一時候補が優先されます。

## 言語・テーマ・データ

［設定とヘルプ］で简体中文、English、日本語と 4 テーマを選べます。作品名、ファイル名、利用者のタグは翻訳されません。進捗などはローカルに保存されます。アプリを終了し、元画像と `%LOCALAPPDATA%\KaikoLibrary\UserData` をそれぞれバックアップしてください。暗号化 ZIP、RAR、7z は非対応です。[よくある問題](troubleshooting.ja.md)もご覧ください。
