# KaikoLibrary

**Your personal doujinshi & CG library.** A bookshelf-style collection manager and reader for Windows.

**Public Beta is being prepared; there is no installer in this repository yet.** The planned first public version is `v1.3.0-beta.1`. Please wait for an official Release here and avoid installers offered by third parties.

![KaikoLibrary Classic with a synthetic test library](screenshots/classic-shelf.png)

Interface languages: **[简体中文](README.md) / English / [日本語](README.ja.md)**. Change language and theme in **Settings & help** after installation.

## Built for personal collections

- **Local-first:** no account required; original images remain in the folders you choose.
- **Bookshelf browsing:** cover views for image folders and ordinary ZIP collections, including nested folders.
- **Organization:** favorites, tags, groups, search, sorting, and filters.
- **Continue reading:** saved progress, page turning, zoom, pan, fullscreen, and thumbnail navigation.
- **Three interface languages and four themes:** KaikoLibrary Classic, Simple Light, Warm Paper, and Forest Study.

Use it for locally held doujinshi, manga, CG sets, illustrations, and other image collections, including adult-oriented works you already possess. KaikoLibrary **does not provide, host, or distribute any works**. It has no online downloader or cloud sync.

## Installation and requirements

Designed for **64-bit Windows 10/11** with **.NET Framework 4.8** and **Microsoft Edge WebView2 Runtime**. If the Runtime is absent, setup may need to contact Microsoft to install it. The installer is **not yet digitally signed by a trusted publisher**, so Windows may show an “Unknown publisher” prompt. Download only from this repository's future official Release and verify its checksum. Not every Windows configuration has been tested. See the [installation guide](docs/installation.en.md).

## Data and privacy

KaikoLibrary does not require you to upload your collection and has no designed active telemetry. Library links, favorites, tags, and reading progress may be stored in local WebView2 user data; original images stay in their folders. Updates and uninstall should preserve the separate user-data directory. The app does not promise anonymity or encrypted storage. Back up **both your originals and app data**. See the [privacy notice](PRIVACY.en.md).
