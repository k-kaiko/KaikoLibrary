# KaikoLibrary

**一座属于你自己的本地同人志与 CG 图集图书馆。** 适用于 Windows 的书架式收藏管理与阅读软件。

**公开 Beta 准备中：本仓库暂未提供安装包。** 首次公开版本拟命名为 `v1.3.0-beta.1`。请等待本仓库的正式 Release，不要从第三方取得所谓“官方安装包”。

![使用虚构书库拍摄的 KaikoLibrary Classic 界面](screenshots/classic-shelf.png)

界面语言：**简体中文 / [English](README.en.md) / [日本語](README.ja.md)**。安装后可在「设置与帮助」中切换语言，也可更换主题。

## 为个人收藏而设计

- **本地优先**：无需账户；原始图片留在你选择的文件夹中。
- **书架浏览**：用封面浏览图片文件夹及普通 ZIP 图集，支持下级目录。
- **整理与查找**：收藏、标签、分组、搜索、排序和筛选。
- **接着阅读**：记录阅读进度；支持翻页、缩放、平移、全屏及缩略图跳页。
- **三种界面语言、四套主题**：KaikoLibrary Classic、Simple Light、Warm Paper、Forest Study。

适合整理本地同人志、漫画、CG 图集、插画和其他图片合集，包括用户自行持有的成人向作品。本软件**不提供、托管或分发作品内容**，也不提供在线下载或云同步。

## 安装与系统要求

面向 **Windows 10/11 64 位**，需要 **.NET Framework 4.8** 与 **Microsoft Edge WebView2 Runtime**。缺少 WebView2 Runtime 时，安装过程可能需要连接微软服务。安装包目前**尚无可信发布者数字签名**，Windows 可能提示“未知发布者”；请仅从本仓库将来的官方 Release 下载并核对校验值。不同系统环境尚未全部实测。详见[安装说明](docs/installation.md)。

## 数据与隐私

KaikoLibrary 不要求上传个人收藏，当前没有设计主动遥测功能。书库关联、收藏、标签和阅读进度可能保存在本机 WebView2 用户数据中；原图仍在原文件夹。卸载与升级应保留独立的用户数据目录。软件不保证匿名或加密存储，请为**原图和应用数据分别备份**。详见[隐私说明](PRIVACY.md)。
