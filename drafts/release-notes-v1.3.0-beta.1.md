# KaikoLibrary v1.3.0-beta.1 — 首次公开 Beta 发行说明草稿

> **草稿，禁止作为 GitHub Release 发布。** 安装包和 SHA-256 尚未确定。内部 P4 RC 的程序显示版本为 `1.3.0-P4-RC`；公开版 `v1.3.0-beta.1` 需要在 P6 核对程序、安装器、文件名及标签是否一致。

KaikoLibrary 是 Windows 上本地优先的同人志、漫画、插画与 CG 图集书架。无需账户，以封面选择作品，在本机管理收藏并接着阅读。软件不提供或分发作品内容。

## 主要功能

- 本地图片文件夹与普通 ZIP 图集阅读，含动态 WebP。
- 书架封面、收藏、标签、分组、搜索、排序与阅读进度。
- 翻页、缩放、平移、全屏、缩略图跳页。
- 简体中文、English、日本語；KaikoLibrary Classic、Simple Light、Warm Paper、Forest Study 四主题。

## 系统与安装

面向 Windows 10/11 64 位，需要 .NET Framework 4.8 和 WebView2 Runtime。**正式安装包发布后**，从此仓库 Releases 下载、核对 SHA-256、关闭旧版后直接覆盖安装。无需先卸载。缺少 Runtime 时安装可能需要网络连接微软服务。首次 Beta 安装包预计无可信发布者数字签名；Windows 可能提示未知发布者。请只使用官方 Release。

## 已知限制

加密 ZIP、RAR、7z 不支持；鼠标侧键可能被驱动或运行环境优先处理；不同 Windows 配置仍需 Beta 验收。当前没有在线下载、云同步或移动端。保存好原图与本机应用数据备份。

## 隐私与反馈

无需上传收藏；应用目前没有设计主动遥测。标签、收藏、搜索历史和进度可能存储在本机。微软 Runtime 安装/更新可能使用网络。本地日志可能含路径；请勿将私人作品、数据库或敏感日志附到[公开 Issues](https://github.com/k-kaiko/KaikoLibrary/issues)。
